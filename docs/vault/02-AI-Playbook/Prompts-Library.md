# Библиотека промптов

## 1. Старт сессии `[Antigravity]`
```text
Прочитай AGENTS.md и docs/vault/00-STATUS.md.
Цель: <один результат>. Критерии: <2-4 условия>. Разрешённые файлы: <список>.
Назови изменение и проверку, сделай минимальный патч. Не добавляй зависимости, не запускай браузер, MCP и субагентов.
В конце: изменённые файлы, реальный вывод проверок, остаточный риск. Обнови docs/vault/00-STATUS.md.
```

## 2. Подгонка под версии `[Antigravity]`
```text
Прочитай AGENTS.md и docs/vault/00-STATUS.md. Файлы <список> не проходят проверки.
1. Покажи версии затронутых пакетов из package-lock.json.
2. Назови причину каждой ошибки (API библиотеки или баг кода).
3. Исправь только несовместимость API, не ослабляя docs/vault/03-Architecture/Security-Invariants.md и тесты.
4. Запусти npm run quality и покажи реальный вывод.
```
